## 키컬러

| 이름 | HEX | RGB | 쓰는 곳 |
|---|---|---|---|
| 메인 오렌지 | `#FF5000` | 255, 80, 0 | 강조 선, 도형, 24px 이상 굵은 글씨 |
| 심볼 오렌지 | `#F37021` | 243, 112, 33 | 어두운 바탕에서만 |
| 글씨용 오렌지 | `#D04000` | 208, 64, 0 | 흰 바탕의 작은 오렌지 글씨 |

## 중립색

| 이름 | HEX | 쓰는 곳 |
|---|---|---|
| 블랙 | `#000000` | 제목 |
| 차콜 | `#222222` | 본문, 선 |
| 진회색 | `#4A4A4A` | 보조 본문 |
| 회색 | `#767676` | 주석, 꼬리표 |
| 연회색 | `#A3A3A3` | 비활성 |
| 선 | `#D9D9D9` / `#EDEDED` | 구분선 |
| 바탕 | `#FFFFFF` / `#F7F7F5` | 지면, 구역 |

- 메인 오렌지, 심볼 오렌지, 차콜, 블랙은 받은 키컬러 표 그대로다
- 글씨용 오렌지와 중립색은 명도 대비 기준에 맞춰 덧붙인 값이다. 쓰는 법은 `rule:orange-usage`
