# 누적 발전을 표현하는 도식 비교

| 도식 | 강점 | 약점 | 임원 보고 적합도 |
|---|---|---|---|
| 이중 루프 | 안쪽 = 행동 수정, 바깥 = 기준 수정. 이 시스템의 실행 루프와 학습 루프 구조와 정확히 일치 | 루프 2개라 배치 설계 필요 | 최상 (판단) |
| 플라이휠 | 한눈에 들어옴, 임원 친숙도 최고 | "쌓인다"가 아니라 "돈다"로 읽힘. 중심에 누적 지표를 넣어 보완 | 높음 |
| 나선 | 회차마다 반경이 커져 누적이 가장 직관적 | 7단계 라벨 배치가 어려움 | 중간 |
| 지층 적층 | "기준 승격 = 층이 하나 쌓임"과 딱 맞음 | 루프 방향이 약함. 루프와 결합 필요 | 중간 |
| 타임라인 + 복리 곡선 | 성과를 말하기에 강함 | 실데이터가 없으면 과장으로 보임 | 데이터 생긴 뒤 |
| 인피니티 루프 | - | DevOps 연상, 상투적, 누적 표현 약함 | 비추천 |

## 근거
- 이중 루프 학습(Argyris): 안쪽 루프는 행동을, 바깥 루프는 기준(governing variables)을 고침 https://sk.sagepub.com/ency/edvol/embed/encyclopedia-of-education-theory-and-philosophy/chpt/single-doubleloop-learning
- SECI 지식 나선: 회차마다 더 큰 규모, 더 높은 수준 https://www.wikipedia.org/wiki/SECI_model_of_knowledge_dimensions
