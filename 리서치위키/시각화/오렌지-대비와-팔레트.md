# 오렌지 명도 대비와 중립 팔레트

- 대비율은 WCAG 공식으로 직접 계산한 값. #FF5000과 #D04000은 재계산으로 확인함

## 대비율

| 색 | 흰 배경 | 검정 배경 | #222222 배경 |
|---|---:|---:|---:|
| #FF5000 (메인) | 약 3.3:1 | 약 6.4:1 | 약 4.9:1 |
| #F37021 (심볼) | 약 2.9:1 | 약 7.2:1 | - |
| #D04000 (작은 글씨용) | 약 4.7:1 | - | - |

## WCAG 기준
- 일반 텍스트 4.5:1
- 큰 텍스트(24px, 또는 18.66px 굵게) 3:1
- 그래픽 요소 3:1
- 출처: https://www.w3.org/WAI/WCAG21/Understanding/contrast-minimum , https://www.w3.org/WAI/WCAG21/Understanding/non-text-contrast

## 운용 규칙
- 흰 배경에서 #FF5000은 선, 도형, 24px 이상 굵은 글씨에만
- 흰 배경의 작은 오렌지 글씨는 #D04000
- #F37021은 흰 배경에서 텍스트·도형 모두 기준 미달. 어두운 배경이나 로고 심볼에만

## 중립 팔레트 (제안)
- 텍스트: #000000 / #222222 / #4A4A4A / #767676 (흰 배경 4.5:1 경계)
- 선·면: #A3A3A3 / #D9D9D9 / #EDEDED / #F7F7F5
- 다크 배경: #0E0F11 / #1A1B1E
