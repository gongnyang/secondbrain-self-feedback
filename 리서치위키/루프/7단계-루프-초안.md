# 7단계 루프 초안과 증명 지표

- 전체가 (제안). 리서치 에이전트가 조사를 토대로 만든 설계안

## 루프

| 단계 | 입력 | 출력 | 담당 |
|---|---|---|---|
| 1. 수집 | 직원 보고서 | 정규화본 + 메타데이터 | Intake |
| 2. 평가 | 정규화본, 기준, 유사 사례 k개 | 판정, 인용 근거가 달린 지적, 수정 제안 | Judge |
| 3. 개선 | 지적 | 직원 수정본 (최대 2회) | 직원 + Coach |
| 4. 실측 기록 | 임원 실제 피드백 | 사전/사후 대조 로그 | Recorder |
| 5. 반성 | 대조 로그 (놓친 것, 오판) | 반성 항목, 패턴 카운터 갱신 | Reflector |
| 6. 큐레이션 | 임계값을 넘은 패턴 | 제안 카드 (근거 링크, 재평가 시뮬레이션) | Curator |
| 7. 승인·배포 | 주간 제안 묶음 | 기준 새 버전 또는 반려 기록, 롤백 지점 | 임원 + Versioner |

## 두 개의 루프로 읽기
- 실행 루프 (1~3): 보고서 한 건을 고침
- 학습 루프 (4~7): 기준 자체를 고침
- 이중 루프 도식과 구조가 같음 → [[누적-도식-비교]]

## "돌릴수록 좋아진다"를 보여줄 지표
- 사전 판정과 임원 판정의 일치율 (월별 추세)
- 임원 지적 사전 포착률: 임원이 실제로 지적한 것 중 시스템이 미리 잡은 비율
- 1차 보고 통과율, 또는 임원 지적 건수 감소
- 승인 제안 채택률과 롤백률 (기준 품질)
- 목표치·벤치마크는 미확인. 도입 전 4주간 기준선 측정 필요
