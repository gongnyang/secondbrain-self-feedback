# 실패 모드와 예방

| 실패 모드 | 무슨 일이 생기나 | 예방 | 근거 |
|---|---|---|---|
| Context collapse | 기준 파일을 통째로 다시 쓰다가 디테일이 사라짐 | 항목 단위 증분 수정만 허용 | https://arxiv.org/abs/2510.04618 |
| 로그 비대화 (context rot) | 입력이 길수록 성능이 불균일하게 떨어짐. 비슷하지만 무관한 내용이 특히 해로움 | 원본 로그는 평가 컨텍스트에서 제외, 관련 상위 k개만 검색해 로드 | https://research.trychroma.com/context-rot |
| 기준 드리프트 | 보정이 쌓이며 원래 임원 기준에서 멀어짐 | 원본 기준(앵커) 파일은 불변, 보정은 별도 레이어. 분기마다 앵커 대비 차이 검토 | (제안) |
| 피드백 과적합 | 한 번 나온 코멘트로 기준이 바뀜 | 서로 다른 건에서 반복될 때만 제안 | (제안) |
| 게이밍 | 직원이 루브릭 키워드만 맞춤 | 정량 근거가 실제로 있는지 확인, 세부 문구 비공개 검토, 최종 지표는 사전 점수가 아니라 임원 실제 판정 | (제안, 실증 출처 미확인) |
