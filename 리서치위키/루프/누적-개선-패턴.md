# 재학습 없이 누적 개선하는 에이전트 패턴

- 모델을 다시 학습시키지 않고, 파일에 쌓인 기록만으로 좋아지는 방식 8가지
- ACE와 Dynamic Cheatsheet의 논문 ID는 검색으로 확인. 나머지는 재검증 안 함(미확인)

| 패턴 | 원리 | 이 프로젝트에 가져올 것 | 출처 |
|---|---|---|---|
| Reflexion | 실패 → 말로 쓴 반성 → 메모리 → 다음 시도에 주입 | 임원 피드백과 사전 평가가 어긋난 건마다 "왜 틀렸나" 한 줄 기록 | https://arxiv.org/abs/2303.11366 |
| Self-Refine / evaluator-optimizer | 생성자와 평가자를 분리해 루프 | 보고서 → 평가 → 수정 → 재평가, 최대 2회 | https://arxiv.org/abs/2303.17651 , https://www.anthropic.com/engineering/building-effective-agents |
| ACE | Generator·Reflector·Curator가 플레이북을 항목 단위로 증분 갱신 | 기준 파일을 항목 ID와 helpful/harmful 카운터로 관리. 통째 재작성 금지 | https://arxiv.org/abs/2510.04618 |
| Dynamic Cheatsheet | 짧고 이전 가능한 요령만 골라 외부 메모리에 보관 | 실패 패턴 치트시트 + 유사 사례 검색 | https://arxiv.org/abs/2504.07952 |
| Voyager | 검증을 통과한 스킬만 라이브러리에 추가 | 임원이 통과시킨 보고서만 모범사례로 등록 | https://arxiv.org/abs/2305.16291 |
| MemGPT / Letta | 상시 컨텍스트와 외부 저장을 계층화 | 기준(core)과 로그(archival) 분리 | https://arxiv.org/abs/2310.08560 |
| Generative Agents | 관찰의 중요도 합이 임계값을 넘으면 상위 반성 생성 | 승격 트리거를 횟수 임계값으로 설정 | https://arxiv.org/abs/2304.03442 |
| Anthropic context engineering | 고신호 토큰만 최소로, 필요할 때 불러오기 | 평가할 때 관련 기준·사례만 로드 | https://www.anthropic.com/engineering/effective-context-engineering-for-ai-agents |
