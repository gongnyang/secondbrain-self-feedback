# 누적 설계 축과 승격 경로

- 대부분 (제안). 폴더명과 임계값은 확정 아님

## 무엇이 쌓이나
- 사례: 보고서와 임원 판정
- 실패 패턴
- 기준 보정: 가중치, 해석
- 용어·선호 표현
- 평가 오판 기록

## 어디에 쌓이나 (제안)
- `logs/`: 원본 기록, 추가만 가능(append-only)
- `patterns.md`: 로그에서 자동 집계한 반복 패턴
- `proposals/`: 기준 변경 제안 큐
- `criteria.md`: 승인본만 들어감, 버전 태그
- `exemplars/`: 모범사례

## 언제 승격되나
- 경로: 로그 → 패턴 → 제안 → 승인 → 기준
- 로그 → 패턴: 같은 유형이 N회 이상, 서로 다른 직원 2명 이상에게서 나올 때
- 패턴 → 제안: 근거 로그 링크가 붙어야 함
- 제안 → 기준: 임원 승인 → [[승인-게이트]]
- N 값은 미확인. 운영하면서 조정할 대상

## 어떻게 정리되나
- 의미가 비슷한 항목은 병합 (ACE의 중복 제거 방식, [[누적-개선-패턴]])
- helpful/harmful 카운터로 감쇠: 오래 안 쓰인 항목은 강등
- 기준 파일은 버전과 변경 사유를 남김
