# 평가 결과 1장 리포트 구성

## 근거가 있는 순서
- 맨 위 띠에 권고와 결정사항 → 근거 블록 → 리스크 → 다음 단계(담당자·기한)
- 출처: https://deckary.com/blog/executive-one-pager-template , https://slidescience.co/executive
- 다음 단계는 소수로 제한, 담당자·기한 명시 https://theaicareerlab.com/glossary/executive-summary

## 적용안 (제안)
1. 한 줄 판정 + 등급 (예: "보완 후 보고 가능. 대안 비교 누락")
2. 핵심 수정사항 3개 (영향도 순, 각 1줄)
3. 축별 스코어 표 (6행) → [[루브릭-초안]]
4. 문제 문장 원문 인용과 수정 예시
5. 다음 행동 (무엇을, 언제까지)

## 넣으면 안 되는 것
- 의미 없는 배경, 그림자, 3D, 아이콘 https://www.holistics.io/blog/data-ink-ratio/
- 본문을 축약만 한 중복 요약 https://www.bizforms.co.kr/guide/list/report/report002.asp
- 결론이 없는 주제형 제목 https://deckary.com/blog/pyramid-principle-consulting
- 강조색 여러 개, 범례 의존
- 점수 남발: 소수점 점수, 축 7개 초과, 근거 인용 없는 점수 (제안, 출처 미확인)
