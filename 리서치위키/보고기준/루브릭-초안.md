# 자가피드백 루브릭 초안

- 전체가 (제안). 축, 가중치, 등급 기준 모두 조사를 토대로 만든 초안
- 임원 인터뷰가 들어오면 2층이 채워지고 1층 가중치도 바뀜

## 2층 구조
- **1층 공통 기준**: 축 6개, 합계 100
- **2층 임원 고유 기준**: 축별 가중치 조정, 금지어·선호 포맷, 추가 체크 문항
- 2층 적용 방식: 공통 점수에 가감하거나 탈락 조건으로 덧씌움

## 등급
- 통과 / 보완 / 재작성

## 1층 축

| 축 | 가중치 | 보는 것 | 통과 | 보완 | 재작성 |
|---|---:|---|---|---|---|
| 1. 결론 선제시 | 25 | 첫 1~2줄에 권고와 요청사항 | 결론과 요청이 다 있음 | 결론만 있음 | 배경부터 시작 |
| 2. 논리 구조 | 20 | 피라미드, MECE, 수평·수직 논리 | 제목만 읽어도 통함, 중복·누락 없음 | 일부 섹션 비약 | 나열식 |
| 3. 근거·숫자 신뢰성 | 20 | 출처, 수치 일관성, 함의 | 모든 수치에 출처, 서로 일치 | 일부 출처 없음 | 수치 불일치 |
| 4. 대안·트레이드오프 | 10 | 2개 이상 대안을 같은 기준으로 비교 | - | - | - |
| 5. 리스크·다음 단계 | 15 | 리스크와 대응, 담당자·기한 | - | - | - |
| 6. 전달 형식 | 10 | 개조식, 한 장 한 메시지, 액션 타이틀 | - | - | - |

- 축 4~6의 등급 기준은 아직 없음
