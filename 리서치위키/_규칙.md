# 위키 작성 규칙

## 페이지 구조
- 한 페이지 = 한 주제, 개조식만 사용
- 파일명 = 한글 주제명, 띄어쓰기는 `-`
- 상단 프론트매터 필수: `title` / `domain` / `confidence` / `updated`
- 다른 페이지 참조는 `[[파일명]]`
- 새 페이지를 만들면 [[index]]와 [[log]]에 한 줄씩 추가

## 근거 표기 (3단계)
- **사실**: 출처 URL이 붙은 내용
- **제안**: 조사를 토대로 만든 설계안. 문단 앞에 `(제안)` 표시
- **미확인**: 출처를 못 찾았거나 재검증 안 된 내용. `미확인`으로 표시

## confidence 값
- `높음`: 1차 출처(공식 문서, 논문)로 확인
- `중간`: 2차 출처(실무 블로그, 분석 글) 위주
- `낮음`: 제안·추정이 대부분

## 도메인
- `루프`: 누적 발전 피드백 루프
- `보고기준`: MBB 임원보고 원칙과 루브릭
- `시각화`: 배선도 스타일과 구현
- `온톨로지`: 경량 온톨로지(전역규칙)
- `세컨드브레인`: 임원 기준 층과 LLM 위키 운영
