# 세컨드브레인 기준 항목 구조

- 전체가 (제안). 출처 없는 설계안

## 항목 유형 8개
- 원칙
- 평가 기준
- 내부 기준: 조직 고유 수치, 임계값, 관행
- 선호 표현
- 금기
- 모범 사례
- 반례
- 과거 피드백

## 공통 필수 필드
- id
- 유형
- 기준 문장
- 원문 인용 (출처 파일, 타임스탬프)
- 해석
- 적용 범위 (보고 유형, 부서, 금액대)
- 예외
- 신뢰도 (상/중/하, 근거 건수)
- 최초·최종 일자
- 승인 상태 (초안 / 임원확인 / 폐기)
- 관련 항목 링크

## 원문과 해석 분리 규칙
- 원문은 인용 블록으로만 쓰고 수정 금지
- 해석은 별도 필드에 쓰고 작성자 표시
- 근거가 1건뿐인 기준은 "가설" 등급
- 임원 승인 전에는 직원 점검에 "참고"로만 노출

## 열린 문제
- 이 8개 유형과 온톨로지 [[엔티티-타입-초안]]의 7개 타입이 겹침 (원칙, 기준, 사례, 피드백). 온톨로지가 타입을 정의하고 세컨드브레인이 그 타입의 내용을 채우는 관계로 정리 필요
