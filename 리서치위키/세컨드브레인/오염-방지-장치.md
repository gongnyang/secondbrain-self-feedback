# 지식 오염·중복·노후화 방지 장치

## 원문 근거가 있는 것
- raw는 불변
- log는 추가만
- lint로 모순, 낡은 주장, 고아 페이지 점검
- git으로 이력 관리
- 출처: [[LLM-위키-패턴]]

## 보강 (제안)
- 주장 단위로 `[^raw/파일]` 각주를 달아 출처 고정
- 직원 입력은 `inbox → proposals`를 거침. 임원 확인 전에는 `confidence: 추정`
- 상충하면 덮어쓰지 않고 `status: superseded`로 남기고 링크
- 쓰기 직후 훅으로 프론트매터 필수 필드 검사 → [[Claude-Code-구현-스펙]]
- 주간 lint: `review_by`가 지난 페이지, 제목이 비슷한 중복 페이지

## 미확인
- confidence 필드를 표준으로 둔 구현체
