# 기준 추출의 실패 모드

| 실패 | 내용 | 예방 |
|---|---|---|
| 말한 기준과 실제 기준의 불일치 | espoused theory vs theory-in-use. 사람은 보통 이 차이를 스스로 모름 | 실제 피드백 기록(행동)과 인터뷰(진술)를 교차 검증. 충돌하면 행동 쪽 우선 + 임원 확인 |
| 인터뷰 1회 과적합 | 한 번 들은 말이 기준으로 굳음 | 근거 1건짜리는 가설 등급. 여러 차례·여러 사례로 확인. 주기적 재인터뷰 |
| 맥락 의존성 | 보고 유형, 시기에 따라 기준이 달라짐 | 적용 범위·예외 필드 필수. 시기(분기말, 위기) 태그 |
| 에이전트 과신 | 시스템 판정을 임원 판정처럼 받아들임 | 결과에 근거 인용과 신뢰도 표시. "임원 판정 대체 아님" 명시 |
