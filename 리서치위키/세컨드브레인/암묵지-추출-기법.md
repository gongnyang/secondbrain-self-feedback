# 암묵지 추출 기법

- 임원 머릿속 평가 기준을 인터뷰로 끌어내는 방법

| 기법 | 원리 | 이 프로젝트에서 쓰는 법 |
|---|---|---|
| CDM (Critical Decision Method) | 실제 겪은 비일상 사건을 4단계(사건 선정, 타임라인, 심화 질문, what-if)로 회고 | "가장 크게 반려했던 보고서 1건"을 시간순으로 재구성 |
| CTA (Cognitive Task Analysis) | CDM, 관찰, think-aloud를 묶은 상위 방법론 | 보고서를 받는 순간부터 판정까지의 판단 흐름도 작성 |
| 래더링 | "왜 중요해?"를 반복해 표면 속성에서 가치로 올라감 | "숫자가 틀렸다"에서 "의사결정 리스크"까지 이어지는 상위 원칙 찾기 |
| Repertory grid | 3개를 보여주고 "둘이 같고 하나가 다른 점"을 물어 판단 축을 뽑음 | 과거 보고서 3건을 동시에 제시해 평가 축 추출 |
| Think-aloud | 실제 과업 중 생각을 소리 내 말하게 함 | 임원이 실물 보고서를 검토하는 장면 녹취 |
| 사례 기반 인터뷰 | 좋은 사례와 나쁜 사례 대조 | 통과 보고서와 반려 보고서 비교 |

- 출처: https://www.gary-klein.com/cdm , https://www.globalcognition.org/cognitive-task-analysis/ , https://pcp-net.org/encyclopaedia/knowl-man.html , https://www.kellysociety.org/repgrids.html
- think-aloud가 말로 하는 기준보다 신뢰도가 높다는 것은 추정

## 녹취록 처리 절차
- 일반 질적연구 관행. 특정 출처는 미확인
1. 개방 코딩: 발언 단위로 태그
2. 축 코딩: 원칙 / 기준 / 임계값 / 금기로 분류
3. 원문 인용과 타임스탬프 첨부
4. "~이면 ~로 판정" 형식의 기준 문장으로 작성
5. 임원에게 보여주고 승인
