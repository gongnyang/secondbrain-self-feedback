# 세컨드브레인 방법론 취사선택

## 가져올 것
- **evergreen 원칙 (사실)**: 원자적, 개념 중심, 촘촘한 링크, 제목은 API처럼, 계층보다 연상 구조 https://notes.andymatuschak.org/Evergreen_notes
- **제목 = 명제형 주장 (판단)**: LLM의 검색·인용 단위로 적합
- **MOC (판단)**: index의 하위 허브로 사용

## 버릴 것 (판단)
- **PARA의 Projects / Areas / Archives 폴더 분류**: 임원 판단기준 위키에 안 맞음. Archive 개념만 노후화 처리용으로 남김 https://fortelabs.com/blog/para/ (본문 직접 확인은 미확인)
- **Zettelkasten의 수기 ID 번호, 손으로 쓰는 문헌노트**: LLM이 대체 가능

## 미확인
- PARA 비판을 LLM 맥락에서 검증한 자료
