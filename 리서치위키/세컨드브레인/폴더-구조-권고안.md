# 폴더 구조와 페이지 규칙 권고안

- 대부분 (제안). 원문 근거는 일부만

## 폴더
- `raw/`: 인터뷰·원자료, 불변. 파일명 `YYYY-MM-DD_출처_주제.md`
- `wiki/bi-intel/`: 비즈니스 인텔리전스 축
- `wiki/bi-brand/`: 브랜드 아이덴티티 축
- `wiki/shared/`: 인물, 조직, 용어
- `index.md`, `log.md`
- `inbox/`: 직원 입력
- `proposals/`: LLM이 제안한 변경 큐
- `.claude/skills/{ingest,query,lint}/`

## 페이지 규칙
- 한 페이지 한 개념, 제목은 명제형 (evergreen 근거, [[방법론-취사선택]])
- 파일명은 조사 보고서에서는 소문자 kebab-case를 권고. 이 리서치위키는 한글 파일명 사용 중
- 길이 상한 200줄: CLAUDE.md 권장치를 빌려온 추정. 위키 페이지용 공식 기준은 미확인

## 프론트매터 (제안)
- `type`: principle / metric / decision / tone / term
- `axis`: intel / brand
- `sources`: raw 경로 목록
- `confidence`: 임원확인 / 추정
- `owner`, `created`, `updated`, `review_by`
- `status`: active / superseded

## index 규칙
- 카테고리별 한 줄 요약 (원문)
- 200줄을 넘으면 축별 하위 index로 분할 (MEMORY.md 상한에서 빌려온 추정)
- ingest 때마다 갱신. lint가 index와 실제 파일의 일치 여부 검사

## 열린 문제
- 루프 조사 쪽 폴더안(`logs/`, `patterns.md`, `criteria.md`, `exemplars/`)과 이 안을 하나로 합쳐야 함 → [[누적-설계-축과-승격-경로]]
