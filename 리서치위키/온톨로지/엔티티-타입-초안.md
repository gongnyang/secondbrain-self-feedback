# 엔티티 타입 초안

- 전체가 (제안). 타입 7개

## 타입

| 타입 | 핵심 속성 | 주요 관계 |
|---|---|---|
| 원칙 | id, 진술, 우선순위, 상태 | 기준으로 구체화됨 |
| 기준 | id, 체크 문구, 근거, 버전, 적용 보고유형 | 원칙에 근거, 보고유형에 적용 |
| 용어 | 정의, 동의어, 금칙어 | 기준·사례에서 사용 |
| 보고유형 | 목적, 필수 구성, 분량 | 기준을 요구, 사례가 예시 |
| 사례 | 날짜, 보고유형, 결과(통과/반려) | 기준 위반·준수, 피드백 유발 |
| 피드백 | 날짜, 대상 사례, 지적 기준, 원문 | 기준을 갱신, 사람이 제시 |
| 사람/조직 | 역할, 선호, 보고 라인 | 피드백 제시, 보고 수신 |

## 액션 (스킬)
- 보고 자가검토: 사례 + 보고유형 + 기준 → 피드백 초안
- 피드백 기록: 피드백 md 생성 + log 추가
- 기준 승격·개정: 피드백이 반복되면 기준 제안, 승인 후 버전 올림 → [[승인-게이트]]
- 용어 정규화
- lint

## 열린 문제
- 비즈니스 인텔리전스 축(지표)과 브랜드 아이덴티티 축(톤, 표기)의 타입이 아직 없음 → [[두-BI-축-공존]]
- 타입 수 상한 7개를 지키려면 지표·톤을 어디에 넣을지 결정 필요
