# 경량 온톨로지의 정의와 스펙트럼

## 정의
- Giunchiglia·Zaihrayeu: 자식 개념이 부모보다 더 구체적인 backbone taxonomy이고, 노드마다 자연어 라벨이 붙음. 웹 디렉터리·분류체계가 원형
  - https://iris.unitn.it/retrieve/66e90e3c-9d28-4362-a549-2dfeea3005d3/050.pdf
  - https://iris.unitn.it/retrieve/231735cb-6918-4b0e-80a1-01501b73e271/071.pdf
- 위키백과: 엄격한 공리 대신 일반적인 연관으로 개념을 이음 https://www.wikipedia.org/wiki/Lightweight_ontology

## 스펙트럼 (McGuinness, "Ontologies Come of Age")
- catalog → 용어집 → 시소러스 → informal is-a → formal is-a → frames → 인스턴스 → 값 제약 → disjoint/inverse → 일반 논리 제약
- 출처: https://www.daml.org/2001/06/ontologies-come-of-age-mit-press-(with-citation).doc , https://wikipedia.com/wiki/Semantic_spectrum

## heavyweight(OWL)와의 차이
- 공리·추론이 있느냐 없느냐
- 이 시스템의 적정 수준 (판단): formal is-a + 관계 몇 개 + 값 제약 일부. 추론은 하지 않음

## 미확인
- SKOS를 시소러스 단계의 표준으로 위치시키는 원문 인용
