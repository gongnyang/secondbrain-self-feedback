# 온톨로지 변경 거버넌스

## SKOS 관행
- 오탈자는 hiddenLabel, 약어와 이형은 altLabel https://www.w3.org/2004/02/skos/core/guide
- 폐기 시 `owl:deprecated true`와 후계 링크. 옛 prefLabel은 후계 개념의 altLabel로 옮김. 버전은 개념이 아니라 스킴 단위 https://lists.w3.org/Archives/Public/public-lod/2010Mar/0271.html
  - 이 폐기 관행은 메일링리스트 제안. 표준 여부 미확인

## md 적용 (제안)
- **버전**: 온톨로지 파일 헤더에 버전과 날짜 + 변경 기록
- **폐기**: active → deprecated → removed. 최소 1주기 유예
- **동의어**: 정식어는 1개. 나머지는 대체어 또는 금지어로 분류
- **드리프트 lint**: 위키·세컨드브레인에서 미등록 ID, 폐기된 ID, 금지어를 찾음
- **승인 주체**
  - 온톨로지: 시스템 관리자
  - 세컨드브레인 기준: 임원 본인 → [[승인-게이트]]
  - LLM은 제안만. 직접 반영 금지 (근거: [[LLM과-온톨로지-결합]]의 품질 문제)
