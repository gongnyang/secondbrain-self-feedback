# 패턴 축적과 기준 제안

- 맡는 역할: 분석 에이전트, 제안 에이전트

## 절차

1. `loop/patterns.md`를 읽고 뜻이 같은 줄을 합친다. 합칠 때 횟수와 근거 로그를 더한다
2. `loop/README.md`의 문턱을 넘고 상태가 `관찰`인 패턴을 고른다
3. 패턴마다 `loop/proposals/_template.md` 양식으로 카드를 만든다
   - 바꿀 내용은 한 줄. 기준 하나에 변경 하나
   - 근거 사례는 로그 링크와 원문 인용으로 2~3건
   - 바꾸면 달라지는 것: 최근 로그에 새 문구를 적용해 판정이 달라지는 건수를 센다. 세지 못했으면 "미확인"
4. 카드를 만든 패턴은 상태를 `제안됨`으로 바꾼다
5. 대기 중인 카드가 5건을 넘으면 실제 피드백과 직접 이어진 것부터 5건만 이번 주 묶음으로 표시한다
6. `loop/metrics.md`에 이번 기간 지표를 한 줄 넣는다. 셀 수 없는 값은 비워 둔다

## 하지 않는 것

- 한 번 나온 차이로 카드를 만들지 않는다
- 기준 파일을 고치지 않는다
- 근거 로그가 없는 카드를 만들지 않는다

## 끝나면

- 이번 주 묶음의 카드 제목을 목록으로 알리고, `/approve`로 넘기라고 안내한다
