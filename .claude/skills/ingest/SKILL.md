# 수집과 정리

- 맡는 역할: 수집 에이전트, 정리 에이전트

## 절차

1. **훑기**: `intake/sources.md`에 적힌 폴더에서 새 파일을 찾아 `intake/inbox/`의 유형별 폴더로 복사한다. 적히지 않은 폴더는 읽지 않는다
2. **옮기기**: `intake/inbox/`의 파일을 한 건씩 처리한다
   - 해시가 같은 파일이 `intake/raw/`에 있으면 건너뛴다
   - 기밀 표시가 있거나 판단이 서지 않으면 `intake/quarantine/`으로 보내고 멈춘다
   - 본문을 그대로 `intake/raw/YYYY-MM-DD_유형_제목.md`로 옮기고 머리에 원경로, 해시, 유형을 적는다. 개인정보는 가린다
3. **온톨로지 초안**: 원자료에 나온 용어, 지표, 표기, 톤을 찾아 `ontology/`에 항목을 만든다
   - `ontology/_schema.md`의 양식과 필수 필드를 따른다
   - 이미 있는 항목이면 `sources`에 경로만 더한다. 정의가 다르면 덮어쓰지 말고 차이를 `loop/proposals/`에 올린다
   - `ontology/index.md`에 한 줄을 넣는다
4. **기준 후보**: 평가 기준으로 읽히는 발언과 피드백을 찾는다
   - 원문을 그대로 인용하고, "~이면 ~로 판정한다" 문장으로 옮긴 해석을 따로 적는다
   - `loop/proposals/_template.md` 양식으로 `loop/proposals/`에 올린다. `brain/criteria/`에는 직접 쓰지 않는다
   - 인터뷰에서 한 말과 실제 피드백 기록이 어긋나면 둘 다 적고 "확인 필요"로 표시한다
5. **기록**: 처리한 파일 수, 만든 항목 수, 올린 후보 수를 알린다

## 하지 않는 것

- `intake/raw/`의 기존 파일을 고치거나 지우지 않는다
- 원자료에 없는 정의나 수치를 채워 넣지 않는다
- 새 타입을 만들지 않는다
