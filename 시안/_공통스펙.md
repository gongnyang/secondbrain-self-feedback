# 배선도 시안 공통 스펙

- 시안 5종이 같은 내용을 서로 다른 스타일로 그린다. 문구는 아래 그대로 쓴다 (스타일 비교가 목적이라 내용이 달라지면 안 됨)
- 보는 사람: 미감에 민감한 의사결정자. 보고 자리에 그대로 띄울 수준이어야 함

## 1. 들어갈 내용 (문구 고정)

### 제목
- 액션 타이틀: `기준을 주면, 보고가 돌 때마다 시스템이 스스로 정교해진다`
- 부제: `세컨드브레인 자가피드백 시스템 · 에이전트 배선도`

### 구조 노드 3개
| 꼬리표 | 이름 | 설명 한 줄 |
|---|---|---|
| 전역규칙 | 경량 온톨로지 | 용어 · 타입 · 표기를 하나로 (비즈니스 인텔리전스 × 브랜드 아이덴티티) |
| 원천 | 수집 | 인터뷰 · 기존 문서 · 과거 피드백 |
| 기준 | 세컨드브레인 | 평가기준 · 내부기준 |

- 세컨드브레인에는 기준이 쌓이는 표시가 붙는다: `v1` `v2` `v3` (최신만 강조)

### 실행 루프: `실행 루프 · 보고서 한 건을 고친다`
| 번호 | 이름 | 설명 한 줄 |
|---|---|---|
| 1 | 초안 입력 | 직원이 보고서 초안을 넣는다 |
| 2 | 자가 평가 | 기준에 비춰 점검한다 |
| 3 | 1장 리포트 | 판정과 수정할 것 3건 |
| 4 | 1차 보고 | 고쳐서 보고한다 |

### 학습 루프: `학습 루프 · 기준 자체를 고친다`
| 번호 | 이름 | 설명 한 줄 |
|---|---|---|
| 5 | 실측 기록 | 실제 피드백과 사전 평가를 대조한다 |
| 6 | 패턴 축적 | 반복되는 차이를 모은다 |
| 7 | 기준 제안 | 근거를 붙여 변경안을 올린다 |
| 8 | 최종 승인 | 주 1회, 승인한 것만 기준이 된다 |

### 연결 (방향 고정)
- 구축 흐름: 수집 → 경량 온톨로지 → 세컨드브레인
- 기준 제공: 세컨드브레인 → 2 자가 평가
- 실행: 1 → 2 → 3 → 4
- 학습: 4 → 5 → 6 → 7 → 8 → 세컨드브레인 (마지막 화살표 라벨: `기준 v+1`)
- 경량 온톨로지는 모든 단계에 적용된다. 노드마다 화살표를 긋지 말고 바닥 띠, 배경 평면, 테두리 같은 "전 구간 적용" 표현으로 처리 (라벨: `전 구간 적용`)

### 하단 한 줄 (숫자 없이 라벨만)
- `돌릴수록 좋아지는지 보는 지표` : `판정 일치율` · `사전 포착률` · `1차 보고 통과율` · `제안 채택률`

### 넣지 말 것
- 로고, 회사명, 아이콘, 이모지, 가짜 수치, 날짜, 작성자
- 위에 없는 문구 (각 시안의 스타일 이름표 1개는 좌상단 구석에 작게 허용. 예: `시안 A · 보드룸 화이트`)

## 2. 색

- 오렌지 `#FF5000`: 메인 강조. 흰 배경 대비 3.3:1이라 선, 도형, 24px 이상 굵은 글씨에만
- 오렌지 `#D04000`: 흰 배경 위 작은 오렌지 글씨용 (대비 4.7:1)
- 오렌지 `#F37021`: 어두운 배경에서만
- 중립: `#000000` `#222222` `#4A4A4A` `#767676` `#A3A3A3` `#D9D9D9` `#EDEDED` `#F7F7F5`, 다크 배경 `#0E0F11` `#1A1B1E`
- 오렌지는 다음에만 쓴다: 학습 루프 경로, 8 최종 승인, `기준 v+1`, 최신 기준 버전 표시. 그 밖에는 금지
- 오렌지 외의 유채색 금지. 그라데이션, 그림자, 3D 금지

## 3. 타이포

- 서체: Pretendard. `<link rel="stylesheet" href="https://cdn.jsdelivr.net/gh/orioncactus/pretendard@v1.3.9/dist/web/static/pretendard.min.css">`
- 폴백: `"Pretendard", "Malgun Gothic", "Apple SD Gothic Neo", sans-serif` (오프라인에서도 깨지지 않게)
- 다른 서체는 시안 지시에 있을 때만 추가
- SVG 안 글씨 최소 크기: viewBox 폭 1200 기준 13 이상
- 숫자는 `font-variant-numeric: tabular-nums`

## 4. 구현

- 파일 1개짜리 HTML. 외부 자원은 위 서체 CSS만 (시안 지시에 서체가 더 있으면 그것까지)
- 도식은 인라인 SVG 하나. `viewBox="0 0 1200 720"` 기준 (세로는 640~760 사이에서 조정 가능), `width:100%`로 반응형, 최대 폭 1280px, 화면 가운데 정렬
- 제목과 부제는 SVG 밖 HTML 텍스트로 써도 되고 SVG 안에 넣어도 됨
- 색은 CSS 변수로 선언
- 선 굵기 1~1.5px (강조 경로는 2px까지). 한 시안 안에서 모서리 반경과 선 굵기를 통일
- 연결선끼리 교차 금지. 선이 노드나 글씨를 지나가면 안 됨
- 화살촉은 `<marker>`로, 선 색과 같게
- 애니메이션은 넣지 않아도 됨. 넣는다면 학습 루프 경로 하나에만, 주기 4초 이상, `prefers-reduced-motion: reduce`에서 끔
- `@media print`에서 배경색 유지 (`print-color-adjust: exact`)
- `<title>`은 `배선도 시안 X`

## 5. 제출 전 스스로 확인

- 글씨가 노드 밖으로 넘치지 않는가 (한글 한 글자 폭 ≈ 글씨 크기, 영문·숫자 ≈ 글씨 크기의 0.55배로 계산)
- 글씨끼리, 노드끼리 겹치지 않는가
- 화살표가 노드 가장자리에서 출발하고 가장자리에 닿는가
- 좌표를 하나씩 따져 선 교차가 없는지 확인했는가
- 1~8 번호, 구조 노드 3개, 루프 이름 2개, 하단 지표 줄, `기준 v+1`, `전 구간 적용`이 전부 들어갔는가
- 오렌지가 허용된 곳에만 쓰였는가
