# 수집

- 원자료가 들어오는 곳. 이 폴더의 실제 파일은 저장소에 올라가지 않는다

## 폴더

| 폴더 | 쓰임 |
|---|---|
| `inbox/interview/` | 인터뷰 녹취, 전사본 |
| `inbox/docs/` | 기존 보고서, 문서 |
| `inbox/feedback/` | 보고서에 남긴 피드백, 메일 발췌 |
| `raw/` | 처리한 원본. 고치지 않는다 |
| `quarantine/` | 기밀이 의심돼 처리하지 않은 파일 |

## 흐름

1. 파일이 `inbox/`에 들어온다
   - 직접 넣거나, 녹음·전사 앱의 저장 경로를 `inbox/interview/`로 잡는다
   - `sources.md`에 적힌 폴더는 `/ingest`가 새 파일을 찾아 `inbox/`로 복사한다
2. `/ingest`가 `inbox/`의 파일을 읽어 `raw/YYYY-MM-DD_유형_제목.md`로 옮긴다 (원문 그대로, 출처와 해시를 머리에 적음)
3. 같은 파일(해시가 같은 것)은 다시 넣지 않는다
4. 기밀 표시가 있거나 판단이 서지 않는 파일은 `quarantine/`으로 보내고 처리하지 않는다

## 원칙

- `sources.md`에 적힌 폴더만 읽는다
- 원본은 고치지 않는다. 해석은 `brain/`과 `ontology/`에 따로 적는다
- 메일은 피드백 문장만 발췌한다
- 개인정보(주민번호, 연락처, 계좌)는 `raw/`로 옮길 때 가린다
